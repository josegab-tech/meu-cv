# Portfólio & Currículo Online — José Gabriel

Seja bem-vindo ao repositório do meu site pessoal e portfólio profissional. O projeto consiste em uma página web responsiva, acessível e otimizada, desenvolvida para apresentar minha trajetória acadêmica no **IFSULDEMINAS**, minhas experiências em **Pesquisa & Desenvolvimento (P&D)**, além de habilidades técnicas e contatos.

**Acesse o site online:** [josegab-tech.github.io/meu-cv/)

---

## Tecnologias Utilizadas

O projeto foi construído utilizando apenas tecnologias *vanilla* (puras), sem o uso de frameworks pesados, garantindo alta performance e carregamento rápido:

- **HTML5:** Estruturação semântica, acessível e focada em SEO (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`).
- **CSS3:** Estilização moderna com CSS Grid, Flexbox, variáveis CSS, animações sutis e layout responsivo (*mobile-first*).
- **JavaScript (ES6+):** Manipulação de DOM, inclusão de ano dinâmico no rodapé e funcionalidade de cópia de e-mail via API Clipboard.
- **GitHub Pages:** Hospedagem e *deploy* contínuo da aplicação.

---

##  Principais Destaques do Site

-  **Design Dark Mode:** Inspirado na paleta de cores oficial do GitHub (`#0d1117` / `#161b22`).
-  **Totalmente Responsivo:** Adapta-se perfeitamente a telas de computadores, tablets e smartphones.
-  **Acessibilidade & Semântica:** Código estruturado segundo boas práticas de arquitetura web.
-  **Navegação Fluida:** Scroll suave entre seções com compensação de cabeçalho fixo.
